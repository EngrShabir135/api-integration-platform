# Streamlit Deployment

This repository includes a Streamlit version of the API Integration Platform for client demos.

## Deploy on Streamlit Community Cloud

Use these settings:

```text
Repository: EngrShabir135/api-integration-platform
Branch: main
Main file path: streamlit_app.py
```

Streamlit Cloud will install dependencies from `requirements.txt` and run the app automatically.

## Demo Login Details

Use either demo client API key inside the app:

```text
demo-key-123
partner-key-456
```

## Local Run

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```
